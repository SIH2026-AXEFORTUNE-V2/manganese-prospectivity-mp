Read this file first. It's the index for every issue in this folder, and it says what's
already done so nobody re-builds it by accident.

**Team of 3.** Seats, not people — whoever's free takes the next unblocked issue for their
seat. The seats exist because of the data contract, not because of who's "the frontend
person": see [../04-data-contract.md](../04-data-contract.md) before opening any issue below.

## Ground rules for every issue

- **Read the file(s) you're about to change before changing them.** Every issue below names
  exact paths - open them first, don't guess the current shape.
- **Don't touch `src/`, `config/`, `data/` unless the issue explicitly says to.** That's the
  validated Python pipeline; see the README's rule about `data/validation/`.
- **Don't rename a data-contract field without updating [../04-data-contract.md](../04-data-contract.md)
  in the same commit and flagging it to the other two seats.**
- **Run `npm run build --prefix web` before calling anything done.** It type-checks the
  whole app; a green build is the minimum bar, not the finish line.
- If a fix isn't obvious, check the app's own `web/AGENTS.md` - Next.js 16 changed enough
  that pattern-matching on older training data will actively mislead you here.
